# Dopamine

# ▶ [TEST GAME](https://dopamine-playtest.vercel.app/?v=support-12)

**One tap opens the latest verified playable build.** The current live build is **Support System v1.2**, layered on the completed Goal 04 30-skill arsenal and pinned to the exact runtime that passed both local and public production browser gates.

The live build contains **60 meaningful support modifiers** across Tempo, Repeat, Conversion, Projectile, Area, DoT, Melee, Movement, and Minion families. Supports can change repeat behavior, cooldown cadence, damage types and conversions, projectile delivery, splash/chain/pierce, ailments, DoTs, knockback/pull, sustain, executes, movement, summons, conditional damage, and risk/reward play.

Each skill now starts with **0/10 support slots unlocked**. Skill pickups roll to unlock that skill's next support slot; stronger monsters improve the chance and later slots become progressively harder. At high monster level the expected pickup curve is approximately **2, 4, 8, 16, 32, 64, 125, 250, 500, and 1000 pickups** for slots 1–10, with slot 10 requiring monster level 60+ and rolling at 0.1% per eligible pickup.

Stage clears drop support items, boss-depth stages drop two, support copies are allocated to individual skills, and the Arsenal shows locked/unlocked sockets, collection progress, compatibility, and the next socket's requirements. The persistent stage summary also keeps its results visible without blocking the Proceed/Depth control.

Final public verification on Vercel passed the support core, mobile hit-testing, and a **3,600-second / 102,858-step / 529-room** supported combat soak with all 30 skills cast and **zero stalls**.

**Dopamine** is an auto-battler action RPG built around deep skill customization, passive-tree buildcraft, monster density, and highly readable combat spectacle.
